## How it is used

The paper is a scientific constraint and source of questions, not a game
specification. The design uses it to distinguish:

- immutable specification from changing physical state;
- addressed environmental information from energy or material supply;
- runtime randomness from programmed input;
- physical substrate/laws from system-specific information;
- a defined coarse-graining from an observation protocol;
- ensemble-level function from microscopic trajectory determinism.

The game does not claim that its node-and-route world models molecular
organization, that a passing generator satisfies an external category, or that
a small trial set measures the
paper's information-theoretic quantities.
